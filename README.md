# Ранжирование фильмов на MovieLens 1M

Как выбрать пять фильмов, которые зритель оценит высоко? На 1 000 209 оценках я сравнил соседские методы, матричную факторизацию, модели по описаниям, две нейросети и двухэтапное ранжирование с CatBoost. В финал вошли 14 конфигураций. **ALS дала лучший тестовый NDCG@5 — 0.8736 и Precision@5 — 0.8249.** Это в среднем 4.12 фильма с оценкой 4 или 5 в первой пятёрке среди отложенных фильмов пользователя. **SGD точнее всех предсказала сами оценки** с RMSE 0.8596.

Весь путь от исходных данных до сравнения на тесте, включая формулы, подбор гиперпараметров и графики обучения, собран в [исследовательском ноутбуке](research.ipynb).

## Как устроена проверка

В каталоге 3 883 фильма, из них 3 706 имеют хотя бы одну оценку. В данных 6 040 пользователей. Каждый оставил не менее 20 оценок. Английские описания удалось сопоставить для 3 804 фильмов из 3 883 (97.97%). Для 79 фильмов без описания контентные методы используют жанровое сходство.

1. **Разбиение.** У каждого пользователя случайно отложил около 20% оценок, всего 200 016. Оставшиеся 800 193 оценки распределил внутри каждого пользователя по пяти фиксированным фолдам. Основной критерий выбора настроек — средний NDCG@5 на пяти валидационных фолдах. Для нейросетей метрики сравниваются на одной и той же эпохе по всем фолдам.
2. **Кандидаты.** На тесте модель получает ID фильмов, для которых оценка пользователя отложена. Значение оценки открывается при расчёте метрик. Медиана — 19 тестовых фильмов на пользователя. В расчёт метрик @5 вошли 5 786 пользователей с минимум пятью кандидатами.
3. **Метрики.** Релевантны оценки 4–5. Precision@5 показывает долю таких фильмов в первой пятёрке, NDCG@5 учитывает ещё и их позиции. Идеальная пятёрка строится по всем кандидатам пользователя до отбора Top-N. При отсутствии релевантных фильмов NDCG пользователя равен нулю. При равных баллах выше ставится фильм с меньшим ID. RMSE считается по всем 200 016 тестовым оценкам у моделей, предсказывающих число на шкале 1–5.
4. **Два этапа.** При CV три фолда дают историю для обучения первого этапа и расчёта признаков. На четвёртом получаем кандидатов и обучаем CatBoostClassifier различать оценки 4–5 и 1–3. Пятый оценивает всю связку. Роли меняются пять раз. В финальном тесте для первого этапа доступны 637 662 оценки, для обучения CatBoost — отдельные 162 531. Самостоятельный ALS использует все 800 193 обучающие оценки.

## Что показали эксперименты

- **Прогноз оценки и порядок рекомендаций.** Для SGD проверено 16 настроек на пяти фолдах, для ALS — 18. Обе используют прогноз из глобального среднего и скалярного произведения скрытых векторов. Лучший по NDCG вариант ALS использует 20 факторов, регуляризацию 20 и 10 итераций. У выбранной SGD — 20 факторов, 20 эпох, шаг 0.01 и регуляризация 0.05. На тесте SGD снижает RMSE относительно ALS на 0.0105, а ALS выигрывает 0.0027 по NDCG@5.
- **Нейросети.** MLP использует ID пользователя и фильма для прогноза оценки. DSSM добавляет жанры и векторы описаний, строит две башни с выходом размерности 32 и обучается отличать оценки 4–5 от 1–2. Тройки пропускаются при расчёте BCE и остаются в списках для ранжирования. DSSM опередила MLP на 0.0081 по тестовому NDCG@5. Обе модели, как и ALS, получают информацию от многих пользователей. Возможное объяснение лидерства ALS — для этих историй хватило 20 регуляризованных факторов. Отдельного эксперимента, который установил бы причину отрыва, здесь нет.
- **Что добавил CatBoost.** В сравнении на одинаковой истории средний NDCG@5 вырос с **0.8306** у первого этапа DSSM до **0.8452** после пересортировки и до **0.8623** после добавления прогноза ALS. Последний шаг улучшил все пять внешних фолдов. Средняя встроенная важность признаков CatBoost — **45.61** у прогноза ALS и **16.74** у балла DSSM. Эффект признака подтверждает прямое сравнение двух моделей на одних кандидатах.
- **Что получилось без DSSM.** На одинаковой тестовой истории CatBoost поднял NDCG@5 с **0.8672** у ALS до **0.8720** для Top-10 и **0.8728** для Top-30. На CV из этих двух вариантов лидировал Top-10. Самостоятельный ALS использовал больше истории и опередил лучший тестовый гибрид на **0.0008**. Статистическая неопределённость этого малого разрыва отдельно не оценивалась.
- **Что дали описания.** Тестовый NDCG@5 вырос с **0.6809** по жанрам до **0.7149** с TF-IDF и **0.7226** с MPNet. В этих моделях текст получает вес 0.7, жанры — 0.3. Для каждого кандидата берётся максимальное сходство с одним из понравившихся фильмов, взвешенное его оценкой. Гипотеза о пользе текста подтвердилась для контентного метода. Даже лучший вариант уступил ALS на **0.1510**. Отдельный вклад текста в гибриде потребовал бы сравнения той же модели с отключёнными текстовыми признаками.

**Граница вывода.** Этот протокол измеряет порядок уже оценённых фильмов у пользователей с историей. Поиск по всему каталогу, качество для нового пользователя и прогноз будущих событий при разбиении по времени требуют других экспериментов.

## Как запустить

Используйте 64-битный CPython 3.11. Команды выполняются из папки с `research.ipynb`. Установка вынесена в [requirements.txt](requirements.txt).

**macOS и Linux**

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

**Windows · PowerShell**. Можно использовать интерпретатор окружения напрямую.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**Данные.** Скачайте и распакуйте MovieLens 1M. Из The Movies Dataset нужны оригинальные `links.csv` и `movies_metadata.csv`, а не уменьшенная таблица соответствий. Расположите файлы так:

```text
research.ipynb
enrich_movies_overviews.py
requirements.txt
ml-1m/
    ratings.dat
    movies.dat
    users.dat
external_data/the_movies_dataset/
    links.csv
    movies_metadata.csv
```

Источники данных и условия использования: [GroupLens MovieLens 1M](https://grouplens.org/datasets/movielens/1m/), [The Movies Dataset](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset). Авторы MovieLens просят указывать источник. F. Maxwell Harper, Joseph A. Konstan (2015), [The MovieLens Datasets: History and Context](https://doi.org/10.1145/2827872).

**Подготовка и запуск**. На Windows в командах ниже замените `python` на `.\.venv\Scripts\python.exe`, если окружение не активировано.

```bash
python enrich_movies_overviews.py
python -m ipykernel install --user --name movielens-ranking --display-name "MovieLens (Python 3.11)"
python -m jupyterlab research.ipynb
```

Скрипт подготовки создаёт рядом с ноутбуком `movies_with_overviews.csv` и `movies_overview_issues.csv`. На исходном снимке получается **3 804** принятых английских описания. Если подготовленный каталог уже есть, можно начать с запуска Jupyter. В Jupyter выберите ядро **MovieLens (Python 3.11)** и выполните **Restart Kernel and Run All Cells**. Сохранённые таблицы и графики можно изучать сразу в ноутбуке.

При первом запуске §7.4 понадобится интернет для загрузки весов. Ревизия модели зафиксирована в ноутбуке. PyTorch использует CUDA при её доступности, затем MPS на Apple Silicon, иначе CPU. Установка CUDA-сборки зависит от платформы и драйвера. Полный перебор включает **80** обучений SGD, **90** обучений ALS и несколько серий обучения нейросетей на пяти фолдах. Планируйте несколько часов. Одна плотная матрица сходства 6 040 × 6 040 в float64 занимает около **278 МиБ**. В процессе одновременно хранятся и другие матрицы. Округлённые результаты нейросетей могут немного различаться между устройствами.
